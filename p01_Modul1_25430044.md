## 2. Ringkasan Dasar Teori

### A. Pengertian Database dan DBMS
* **Database (Basis Data):** Serangkaian data atau kumpulan data yang dikelola sedemikian rupa sehingga saling berhubungan satu sama lain, yang bertujuan untuk mempermudah pengguna dalam mendapatkan informasi dari suatu sistem.
* **DBMS (Database Management System):** Perangkat lunak yang digunakan untuk mengelola database, salah satu contohnya adalah MariaDB atau MySQL.

### B. Data Definition Language (DDL)
* **DDL** adalah sekelompok perintah SQL yang difungsikan untuk mendefinisikan struktur dari suatu database, serta mengatur objek-objek di dalamnya seperti pembuatan, pengubahan, atau penghapusan tabel, indeks, pengguna, dan database itu sendiri.
* Contoh perintah DDL:
  * `CREATE DATABASE`: Untuk membuat database baru.
  * `CREATE TABLE`: Untuk membuat tabel baru.
  * `DROP`: Untuk menghapus objek database.

## 4. Jawaban Titik Analisis

* **Titik Analisis 1 (MySQL vs MariaDB):** 
  Meskipun pada XAMPP tertulis menu `MySQL`, server yang digunakan sebenarnya adalah **MariaDB**. Namun, dokumentasi atau referensi MariaDB tetap wajib dirujuk apabila terjadi *error* pada fitur tertentu (seperti penanganan sistem autentikasi atau kode kesalahan secara spesifik).
  
* **Titik Analisis 2 (Pesan Kesalahan ERROR 1045):** 
  Pesan galat `ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: NO)` menandakan bahwa akun yang digunakan tidak menyertakan kata sandi, yang ditunjukkan oleh keterangan `using password: NO`.
  
* **Titik Analisis 3 (Perbedaan ERROR 1044 dan ERROR 1045):**
  * **ERROR 1044:** Terjadi ketika proses autentikasi berhasil, namun pengguna dilarang melakukan operasi pada database tertentu karena tidak memiliki izin yang cukup (kegagalan otoritas/*privileges*).
  * **ERROR 1045:** Terjadi pada tahap awal permohonan akses akibat kegagalan autentikasi (nama pengguna atau kata sandi tidak valid).

## 5. Hasil Latihan dan Modifikasi

Pada sesi latihan, dilakukan pengujian akses menggunakan perintah:
```sql
mysql -u root -p
Enter password: *************** 
ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: YES)
```
Keterangan di atas menandakan bahwa akun *username* `root` sudah memiliki kata sandi (`using password: YES`). Karena ingin mengubah hak akses dan nama pengguna, dilakukan modifikasi menggunakan perintah SQL berikut:

```sql
RENAME USER 'root'@'localhost' TO 'Bergasgm111'@'localhost', 'root'@'127.0.0.1' TO 'Bergasgm111'@'127.0.0.1';
```

**Kesimpulan Latihan:** Berhasil melakukan perubahan nama pengguna serta mengelola kredensial akun database dengan benar.
