## 4. Jawaban Titik Analisis
Titik analisis 1 (MySQL vs MariaDB):
Meskipun pada XAMPP bertuliskan Mysql tetapi server yang digunakan tetaplah MariaDB, namun dokumentasi MariaDB wajib di kirim apabila terjadi Eror pada fitur tertentu contohnya seperti penanganan sistem autentivikasi atau kode kesalahan secara spesifik

Titik Analisis 2 (Pesan Kesalahan ERROR 1045):
Pesan galat ERROR 1045 (28000): Access denied for user 'root'@'localhost' (using password: NO)
Menandakan akun yang di gunakan tidak memiliki password karena keterangan pada "using no password: NO"

Titik Analisis 3 (Perbedaan ERROR 1044 dan ERROR 1045):

Perbedaannya antara lain
ERROR 1044 terjadi ketika proses autentikasi berhasil, namun pengguna dilarang melakukan operasi pada database tertentu karena tidak memiliki izin (kegagalan otoritas).

ERROR 1045 terjadi pada tahap awal permohonan akses akibat kegagalan autentikasi (nama pengguna atau kata sandi tidak valid).
